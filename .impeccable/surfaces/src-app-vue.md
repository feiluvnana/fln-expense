# Surface Brief: FLN Expense Core Shell & Views

## Scope and Mode
- Target: `src/App.vue` (and child views/components)
- Mode: Operate

## Direction contract

THESIS: Refuse generic sterile cold-blue dashboard templates and noisy emoji-spam headers; own a calming, tactile, mobile-first feline sanctuary inspired by the sleeping ginger-and-white tabby cat, uniting ergonomic single-thumb mobile navigation with Dinero.js arithmetic precision.

OWN-WORLD: Palette of warm ginger (#DF6826, #F97316), cream backgrounds (#FAF7F2, #F3ECE1, #FFFFFF), deep espresso ink (#28211E, #433934, #7C6E66), serene sage (#10B981) for income, terracotta persimmon (#EA580C) for expense, soft pill radii (12-24px), subtle warm drop shadows, and clean, consistent bespoke SVG stroke icons.

STORY: The user feels an immediate sense of warmth and zero financial anxiety; on mobile, their thumb effortlessly sweeps between Dashboard and All Transactions via a native-feeling bottom navigation bar; tapping the elevated central (+) action summons a tactile bottom sheet with clear visual category buttons; on desktop, a cozy sidebar provides calm overview and rich chart analysis.

FIRST VIEWPORT: Mobile: Top bar with cute cat mascot emblem and language toggle; hero balance card in warm ginger-cream showing net totals by currency; interactive financial chart with segmented mode pills; floating bottom bar anchored with Dashboard, Transactions, and a prominent elevated (+) Add button. Desktop: Left sidebar with branding and navigation; multi-column responsive dashboard with currency stat cards, expansive analytics chart, and recent transactions.

FORM: Feline Cozy Sanctuary (warm ginger & cream palette, organic pill controls, bespoke stroke SVG iconography).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
